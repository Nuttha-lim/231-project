# CO Valley

เกมจำลองทำฟาร์มบนเดสก์ท็อป พัฒนาด้วย Java 21 และ Java Swing โดยทีม 5 คน ผู้เล่นสำรวจแผนที่ ปลูกพืช จัดการไอเทม ซื้อขายสินค้า และบันทึกความคืบหน้าของเกมได้

## งานที่รับผิดชอบ

- ออกแบบ UX/UI ของเกม
- พัฒนาการเคลื่อนที่ตัวละคร 4 ทิศทางและแอนิเมชันตามทิศทางการเดิน
- พัฒนาระบบป้องกันการเดินผ่านรั้วและการเปลี่ยนฉากระหว่างแผนที่
- ทดสอบการเล่นเกม

## ทดลองรัน

ใช้ Windows และติดตั้ง JDK 21 ให้เรียก `java` และ `javac` ได้ จากโฟลเดอร์โปรเจกต์รัน:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

สคริปต์จะแตกไฟล์ภาพ เสียง และฟอนต์จาก ZIP ที่มาพร้อมโปรเจกต์ จากนั้นคอมไพล์และเปิดเกม หากต้องการคอมไพล์โดยไม่เปิดเกม ให้เติม `-BuildOnly` เกมใช้พื้นที่แสดงผล 1366 × 768 พิกเซล โดยต้องเผื่อพื้นที่สำหรับขอบหน้าต่างด้วย
