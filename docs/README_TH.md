# CO Valley

เกมจำลองทำฟาร์มบนเดสก์ท็อป พัฒนาด้วย Java 21 และ Java Swing เป็นโปรเจกต์กลุ่ม 5 คน ผู้เล่นเดินข้ามแผนที่ ปลูกพืช จัดกระเป๋า ซื้อขายของ และบันทึกเกมได้

## ส่วนที่ Nuttha รับผิดชอบ

- ออกแบบ UX/UI ของเกม
- เขียนการเคลื่อนที่ตัวละคร 4 ทิศทางและแอนิเมชันตามทิศ
- ทำการบล็อกการเดินบริเวณรั้วและเปลี่ยนฉากระหว่างแผนที่
- ทดสอบการเล่นเกม

บทบาทนี้อ้างอิงเรซูเม่ที่เจ้าของพอร์ตให้มา ฟีเจอร์กระเป๋า ปลูกพืช ร้านค้า และบันทึกเกมใน README หลักเป็นผลงานของทีม ไม่ได้ระบุว่า Nuttha ทำทั้งหมด

## ทดลองรัน

ใช้ Windows และติดตั้ง JDK 21 ให้เรียก `java` และ `javac` ได้ จากโฟลเดอร์โปรเจกต์รัน:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

สคริปต์คืนไฟล์ภาพ เสียง และฟอนต์จาก ZIP เดิม แล้วคอมไพล์และเปิดเกม ถ้าต้องการตรวจเฉพาะการคอมไพล์ให้เติม `-BuildOnly` ขนาดพื้นที่เล่น 1366 × 768 ต้องเผื่อขอบหน้าต่างเพิ่มเติม
